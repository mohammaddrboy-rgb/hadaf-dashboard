# داشبورد آموزشگاه هدف

داشبورد RTL برای مدیریت صنف‌ها، شاگردان، پرسنل، مالی و گزارش‌های آموزشگاه هدف. همه داده‌ها در `localStorage` مرورگر ذخیره می‌شوند.

## ساختار پروژه

```
hadaf-dashboard/
├── index.html      # اسکلت HTML
├── css/app.css     # استایل‌ها
├── js/seed.js      # دادهٔ نمونهٔ اولیه
├── js/app.js       # منطق برنامه
└── assets/logo.png # لوگو
```

## اجرای محلی

```bash
cd hadaf-dashboard
python3 -m http.server 8080
```

سپس در مرورگر باز کنید: `http://127.0.0.1:8080`

برای خروجی Excel به CDN کتابخانهٔ SheetJS وابسته است. بدون اینترنت، بخش خروجی Excel کار نمی‌کند.

## نقش‌ها

| نقش | دسترسی |
|-----|--------|
| سهامدار | همه بخش‌ها |
| مدیر شعبه | همه بخش‌ها به‌جز سهامداران |
| مدرس | صنف‌های خودش و برنامهٔ کلی |
| کارمند | پذیرش، ثبت‌نام و امور روزمره |

## امنیت

این برنامه یک SPA آفلاین است، نه یک سامانهٔ احراز هویت سروری.

- رمزهای نمونه در `js/seed.js` قرار دارند.
- هرکسی به فایل‌ها دسترسی داشته باشد می‌تواند آن‌ها را ببیند.
- برای دادهٔ واقعاً محرمانه، نسخهٔ سروری با backend لازم است.

## استقرار

فایل‌های استاتیک را روی هر وب‌سروری (Nginx، Apache، Cloudflare Pages) در root سایت قرار دهید.

مثال Nginx:

```nginx
server {
    listen 80;
    server_name hadaf.example.com;
    root /var/www/hadaf;
    index index.html;
    location / {
        try_files $uri $uri/ /index.html;
    }
}
```
